# Enterprise Insurance Intelligence Platform

**Transforming raw insurance operations into trusted executive intelligence through data governance, security, quality engineering, and business analytics.**

This project demonstrates the design of a modern analytics platform for an insurance enterprise using PostgreSQL and Power BI. Rather than focusing only on reporting, the platform addresses the complete data lifecycle—from raw ingestion and standardization to governed analytics and executive decision-making.

The solution is built around enterprise data engineering principles, including metadata-driven standardization, data quality validation, role-based analytical views, secure handling of sensitive information, and business-oriented data marts for Finance, Sales, Marketing, Underwriting, and Executive leadership.

The objective is not simply to answer business questions, but to ensure that every dashboard is built on data that is accurate, governed, secure, and trusted.

**Key capabilities**

* Enterprise Snowflake Data Model
* Data Governance & Sensitivity Classification
* Data Quality Framework (Profiling, Validation & Reconciliation)
* Secure Business Views for Role-Based Analytics
* Customer 360°, Policy 360° and Agent 360° Business Models
* Finance, Sales, Marketing, Underwriting and Executive Data Marts
* Executive Power BI Dashboards with Business Storytelling
* PostgreSQL-based Metadata-Driven SQL Architecture
